# 拾光咖啡 · 咖啡点单小程序

一个原生微信小程序实现的咖啡点单 Demo：从选品、规格加料、购物车、优惠券到下单和取餐，全流程可跑通，**不依赖任何后端**。

## 功能

| 页面 | 说明 |
| --- | --- |
| `pages/index` 点单 | 门店信息卡（营业状态 / 到店自取 · 堂食切换）、活动条、6 个分类横滑、17 款商品、快捷加购、悬浮购物车条 |
| `pages/detail` 商品详情 | 杯型 / 温度 / 甜度 / 加料四组规格，数量步进，实时算价，加购后返回 |
| `pages/cart` 确认订单 | 清单增删改、取餐方式、优惠券选择、备注、小计 / 会员立减 / 券抵扣 / 应付 |
| `pages/orders` 我的订单 | 全部 / 制作中 / 已取餐筛选，再来一单、确认取餐、下拉刷新 |
| `pages/mine` 我的 | 会员卡、订单 / 杯数 / 券统计、门店信息、关于、清空本地数据 |

计价规则：大杯 +3、换燕麦奶 +2、加浓缩 +3、加淡奶油 +4；满 20 元会员立减 2 元，可与满减券叠加（满 20 减 5 / 满 38 减 8 / 满 50 减 12）。

## 技术说明

- **原生小程序**：WXML / WXSS / JS，无 npm、无框架、无 TypeScript。
- **数据层在本地**：`utils/store.js` 统一封装 `wx.setStorageSync`，购物车、订单、优惠券、会员信息都存放在手机本地，卸载或清理缓存后不可恢复。所有读写都有 try/catch 兜底，失败会 toast 提示，不会静默失败。
- **菜单数据**：`utils/menu.js`，商品、规格选项、门店信息集中在一处，改这里就能换菜单。
- **金额**：统一走 `utils/util.js` 的 `money()`（保留两位、避免浮点误差），页面只渲染预计算好的字符串，WXML 里不做运算。

## 本地运行

1. 用微信开发者工具「导入项目」，选择本目录。
2. `project.config.json` 里的 `appid` 换成你自己的小程序 AppID（真机预览 / 调试必须是真实 AppID，游客模式不支持真机）。
3. 编译即可运行，不需要构建 npm、不需要后端。

不想开 IDE 时，可以直接跑数据层的自测：

```bash
node tools/check.js
```

会检查 JSON 严格性、页面文件齐全、tabBar 图标存在、WXML 表达式合法性、WXSS 括号配对，并用 mock 的 `wx` 跑一遍加购合并、算价、券核销、下单、再来一单、确认取餐。

## 已知边界

- 单机数据：换设备不同步，清缓存即清空。
- 未接微信支付，`提交订单` 只写本地订单记录。
- 未接登录，会员信息是本地固定示例数据。
- 门店、菜单、价格都是示例值，接真实业务需要换成接口。
